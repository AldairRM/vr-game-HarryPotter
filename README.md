# 🧙‍♂️ Projeto de Experimentos em VR com Unity

Este é um projeto pessoal onde explorei como usar a Unity para criar jogos com realidade virtual.  
O universo de Harry Potter serviu de inspiração as funcionalidades mágicas! ✨
Obviamente, para testar o projeto você precisa de um óculos virtual, por isso recomendo o uso do Meta Quest 2 ou 3. 

> ⚠️ Atenção: Este não é um jogo completo, apenas um projeto de estudo!

---

## 🔮 Funcionalidades

No projeto, você poderá:

- Soltar feitiços padrão movimentando a varinha em direção aos inimigos.
- Usar comandos de voz do Windows para ativar feitiços especiais:
  - `Lumos` → Aparece um clarão de luz na ponta da varinha.
  - `Nox` → Remove o clarão de luz do Lumos.
  - `Bombarda` → Feitiço poderoso para atacar inimigos.

---

## 🛠 Sobre o projeto

- Ferramenta usada: Unity
- Tipo de experiência: Realidade Virtual 
- Objetivo: Aprender conceitos de VR e integração de comandos de voz com interação 3D.
